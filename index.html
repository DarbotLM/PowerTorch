Implemented foundation

Useful now. Explicit later.

T

Tensor core

Dense CPU storage, shape/stride checks, dtype metadata, add, multiply, subtract, divide, sigmoid, sum, and mean.

∇

Autograd

Reverse-mode arithmetic and sigmoid/sum/mean gradients with persistent parameter state.

A

AdamW

Float32/float64 first and second moments, bias correction, decoupled weight decay, and gradient clearing.

D

DirectML

Native adapter/device creation, compiled DML operator execution, D3D12 upload/readback, fencing, and float32 add parity.

S

Safetensors

Bounded JSON header parsing, dtype/shape/offset validation, overlap detection, and real tensor reads.

O

ONNX interop

DirectML ONNX Runtime metadata loading in an isolated native CLI host, with PowerShell receiving structured JSON.

Security by construction

No executable Python pickle boundary.

Safetensors is parsed with strict header, dtype, shape, offset, overlap, and file-bound checks. ONNX and TorchScript-like archives are treated as untrusted, and arbitrary executable deserialization is rejected.
